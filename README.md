# Làng Bạn Nhỏ

Game web nuôi thú, làm vườn, câu cá, trang trí ngôi nhà và học vui (Toán, Âm nhạc, Tiếng Anh, Tiếng Việt). Không cần build: mở `index.html` hoặc chạy `python3 -m http.server`. Chạy test: `npm test`.

Tên cũ là **Pet Destiny**. Tên kho GitHub (`pet-destiny`), khoá lưu trong trình duyệt (`pet-destiny-*`) và trường `app` trong file sao lưu được giữ nguyên có chủ đích để không làm mất dữ liệu người chơi và vẫn nhập được file sao lưu cũ. Xem `HANDOFF.md` để biết chi tiết kiến trúc.
